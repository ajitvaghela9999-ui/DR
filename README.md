# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/d9e826f5-1d32-4db8-b3f8-e0568259dc32

## Run Locally

**Prerequisites:** Node.js, MongoDB (Installed and Running)

The easiest way to run this project reliably is to use the built-in workflow.

1. **Start Project:**
   Type `/run-project` into the chat.

Alternatively, follow these manual steps:

1. **Install Dependencies:**
   `npm install`
2. **Ensure MongoDB is Running**
   (Win + R -> `services.msc` -> Find 'MongoDB' -> Start)
3. **Run the app:**
   `npm run dev`
